# Generated Property Data

`properties.raw.json` contains the unmodified synthetic response generated by Google AI Studio.

`properties.validated.json` is written only after the raw response passes the project's Zod data contract.

All properties, addresses, sponsors, businesses, and URLs are fictional. No real client or personal data was used.

The available AI Studio interface did not expose a structured-output setting. The JSON Schema was included directly in the prompt, and the response was validated locally before use.
