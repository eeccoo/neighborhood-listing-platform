# Neighborhood Listing Platform

A community-focused property platform that connects residents with local properties, neighborhood sponsors, and accessible support.

## Live Deployment

[View the deployed application](https://neighborhood-listing-platform-beryl.vercel.app)

## Features

- Property listings
- Neighborhood sponsors
- Accessible voice-help information
- Responsive and accessible page structure

## Technology Stack

- Next.js App Router
- TypeScript
- Tailwind CSS
- GitHub
- Vercel

## Run Locally

Install the dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open `http://localhost:3000` in a browser.

## Verification

The following commands completed successfully:

```bash
npm run lint
npm run build
```

The local page and deployed application were also inspected in the browser.
